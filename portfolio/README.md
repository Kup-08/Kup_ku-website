# Kup_ku Portfolio Site

Multi-page personal website and portfolio with a shared content config.

## Pages

- `index.html` - Home
- `about.html` - About
- `projects.html` - Projects
- `experience.html` - Experience and Certifications
- `service.html` - Service
- `community.html` - Community
- `contact.html` - Contact

## Content Editing

Edit all profile data in `assets/js/content.js`:

- Profile and bio
- Projects
- Certifications and skills
- Service details
- Community text
- Social links
- Contact details and resume path

## Social Links

Update each `url` in `siteContent.socials`.

If a URL is empty, the site shows a disabled placeholder link.

## Resume Download

Current placeholder file:

- `assets/resume/Kup_ku_Resume.txt`

To use a real resume:

1. Add your resume file under `assets/resume/`.
2. Update `contact.resumeUrl` in `assets/js/content.js`.

## Run Locally

Open `index.html` directly in your browser, or use a local static server.
